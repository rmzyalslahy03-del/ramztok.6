🔌 واجهة برمجة التطبيقات (API)

يستخدم تطبيق RamzTok Supabase كخلفية. يمكنك التفاعل مع قاعدة البيانات مباشرة عبر REST API أو WebSocket.

// مثال: جلب الفيديوهات الأكثر إعجاباً
fetch('https://fqowxtghefuykxyyrttk.supabase.co/rest/v1/videos?order=likes.desc', {
  headers: { 'apikey': 'sb_publishable_StGuaVLO7lfCsKF0Fr1dHQ_m10dbTOO' }
})
.then(res => res.json())
.then(console.log);

ملاحظة: يجب استخدام المفتاح العام (anon key) فقط للقراءة العامة. العمليات التي تتطلب كتابة تحتاج مصادقة.

🛠️ أدوات المساعدة (Utilities)

  • مولد رمز مميز (JWT): لتجربة المصادقة.
  • محاكي قاعدة البيانات: يمكنك استخدام Supabase Local Emulator للتطوير المحلي.
  • مكتبة المساعد (SDK): @ramztok/sdk
