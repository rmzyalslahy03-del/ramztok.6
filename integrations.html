تكاملات خارجية

استخدم واجهاتنا وأدواتنا لربط تطبيقاتك وخدماتك بمنصة RamzTok.

REST API
ادمج منصة RamzTok مع أنظمتك عبر واجهة برمجة تطبيقات قوية ومتوافقة مع معايير REST.
Supabase Client
استخدم نفس طبقة البيانات التي يعتمد عليها RamzTok مباشرة عبر مكتبة Supabase.
Webhooks
استقبل إشعارات فورية عند حدوث أحداث مثل رفع فيديو جديد أو إعجاب.
SDK للمطورين
مكتبات جاهزة بلغات JavaScript, Python, و Dart لتسهيل التكامل مع التطبيق.
المساعدون (AI Bots)
ربط روبوتات الدردشة والتفاعل التلقائي مع المحتوى عبر واجهات ذكية.
تحليلات خارجية
أرسل بيانات التفاعل والإحصائيات إلى أنظمة التحليلات الخاصة بك مثل Google Analytics أو Matomo.
💡 مثال سريع لاستدعاء API في جافاسكريبت:

fetch('https://api.ramztok.com/videos?limit=5', {
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
})
.then(res => res.json())
.then(data => console.log(data));
📦 تثبيت مكتبة المساعد JavaScript (npm):

npm install @ramztok/sdk-js

import { RamzTokClient } from '@ramztok/sdk-js';
const client = new RamzTokClient({ apiKey: 'YOUR_API_KEY' });
client.getTrendingVideos().then(console.log);
